## 5. Данные

| Набор | Происхождение |
|---|---|
| Компании, руководители, финансовые показатели, кредитные истории, обороты, документы, заявки | **Синтетические**, созданы командой (`mocks/fixtures.json`, `backend/app/seed.py`, генератор в `mocks/app.py`). Совпадения с реальными лицами и организациями случайны |
| Новостная лента | Демо-контент, написанный командой. Значение ключевой ставки (14%) и дата следующего заседания взяты из открытых данных Банка России |
| Справочник ОКВЭД (фрагмент) | Открытый классификатор ОК 029-2014 (используются коды и названия) |
| Выписка по счёту | Синтетическая (`testdata/bank_statement_sample.csv`) |

Покупные и закрытые датасеты не используются.

## 6. Смоделированные интеграции

Все внешние системы воспроизводит сервис `mocks` с упрощёнными контрактами, сохраняющими смысл интеграции. Обращений к реальным системам нет.

| Реальная система | Мок | Что сохранено |
|---|---|---|
| ЕГРЮЛ/ЕГРИП (ФНС России) | `GET /egrul/v1/companies/{inn}` | Статус, дата регистрации, ОКВЭД, руководитель, учредители, адрес |
| Сервис ФНС «Прозрачный бизнес» | `GET /fns/v1/transparent-business/{inn}` | Выручка, расходы, налоги, недоимка, численность, отметки (массовый адрес, недостоверность, дисквалификация) |
| Бюро кредитных историй | `POST /bki/v1/reports` | Обязательное согласие (`consent_id`), балл, просрочки, обязательства, запросы |
| Антифрод-система банка | `POST /antifraud/v1/check` | Уровень риска и причины |
| АБС банка: счета | `GET /abs/v1/accounts/{inn}` | Наличие счёта, стаж, обороты |
| АБС банка: выдача | `POST /abs/v1/loans` | Открытие ссудного счёта, идемпотентность по заявке |
| Электронная подпись | Встроено в backend | Простая электронная подпись одноразовым кодом из уведомлений кабинета |
| Каналы уведомлений (SMS, e-mail, push) | Не используются по условию кейса | Уведомления только внутри продукта |
